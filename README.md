# 🐍 Employee Salary and Promotion Calculator

## 💻 About the Project

This project was developed using Python to practice programming logic and conditional structures.

The program collects employee information, including name, years of service, current salary, and goal achievement percentage.

Based on the provided information, it calculates the final salary and checks the conditions for a possible promotion.

## ⚙️ Features

- Employee name input.
- Years of service input.
- Current salary input.
- Goal achievement percentage input.
- Salary adjustment calculation.
- Promotion eligibility verification.
- Final salary display.

## 🛠️ Technologies Used

- **Python 3**
- Conditional statements (`if`, `elif`, and `else`).
- Logical operators (`and`).
- User input with `input()`.
- Data type conversion with `int()` and `float()`.
- Output formatting with `print()` and f-strings.

## 🧠 Programming Logic

The program uses conditional statements to determine salary adjustments based on years of service and employee performance.

| Condition | Salary Increase |
|---|---:|
| 5 or more years of service and goal achievement of 80% or higher | 30% |
| 5 or more years of service and goal achievement below 80% | 20% |
| Other conditions | No increase |

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Run the Python file.
4. Enter the requested employee information.
5. Check the final salary calculation.

## 🎯 Learning Objectives

Practice fundamental Python concepts, develop logical thinking, and understand how conditional structures can be used to solve everyday business problems.
